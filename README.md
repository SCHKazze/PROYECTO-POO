Bienvenidos a nuestro repositorio!

El proyecto consiste en el desarrollo de un Sistema de Gestión y Registro para Taller Mecánico, una aplicación de escritorio diseñada para automatizar y optimizar la administración de clientes y vehículos en un taller de servicio técnico.

¿De qué se trata el proyecto?
El objetivo principal es reemplazar los métodos tradicionales de registro en papel o tablas desorganizadas mediante una interfaz gráfica moderna, intuitiva y rápida. La aplicación permite realizar las operaciones principales de administración de datos: registrar nuevos clientes, consultar la información en tiempo real, actualizar datos y eliminar registros según sea necesario.

El desarrollo está fundamentado en la Programación Orientada a Objetos (POO) y fue construido utilizando Java 17 con la librería gráfica Java Swing.
